HYPOTHESIS

Aperture and cover

α = a/M; rA = r0√(1 − (αc/α)²) for α > αc.

C = 1 when L ≥ Lseal; P = (1 − C) · 1[rA > 0].

These assumed laws have no observational validation here. A passage indicator is not a calculated travel result.
GFM REPRESENTATION

Trace-character transform

yk = ⅓ Σx∈GF9 fx exp(2πi Tr(kx)/3).

GF9 = GF3[α] / (α² + 1).

The field generator α is distinct from spin. The inverse uses negative phase. This transform does not alter spacetime or create missing information.
RELATIVITY

Neutral Kerr light paths

Σ = r² + a² cos²θ; Δ = r² − 2Mr + a².

R = [E(r²+a²) − aLz]² − Δ[QC+(Lz−aE)²].

Θ = QC + a²E²cos²θ − Lz²cot²θ.

Carter's separated equations are integrated in Mino parameter. QC is the Carter constant; electric charge is zero. G=c=M=1.
NUMERICAL SCOPE

Exterior test-light approximation

Adaptive integration calculates light paths in a fixed Kerr metric. Both branches use the same exterior.

Rays stop at documented exterior horizon/polar guards or numerical limits. No plasma, evolving spacetime, radiative transfer, solid formation or wormhole metric is solved. The display is a coordinate embedding, not proper distance.
ESTABLISHED MODEL

Kerr exterior

WHAT EVIDENCE MEANS

Verification and validation

Automated tests and analytic comparisons check the implementation. External observational validation has not been performed for this application.

Near-critical or terminated rays can remain unresolved. The report preserves errors and stopping reasons.

IDENTIFIABILITY

Same observations, same likelihood

If the branches produce identical observations, those observations cannot update their relative prior probabilities. A GFM transform cannot identify a cover from identical input.
