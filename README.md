# GFM Black Hole Postulation Console

**JA21 console 2.0.0 · Windows x64 · local calculation workers**

Open **Start GFM Console.cmd** or **GfmJa21.exe**. The native JA21 window now
contains both repositories: the current cylindrical electromagnetic pulse
laboratory and the complete supplied GFM Phase Texture v3.0.0 experiment.
The instrument bar opens phase/plasma/cover pulse layers, periodic MHD and iron
texture, aperture/aggie postulates, computed Kerr rays, observations, source
audits, corrected GR references and the original GFM transform terminal.

Read **READ ME - GFM Console.txt** for launch, performance and model boundaries.
The local instruments need no localhost server. The native host uses standard
WPF WebView2 with the pinned SDK; a WebView2 Evergreen Runtime is required.
The package does not change Windows script or application policy.

For a GitHub download, extract the entire ZIP into a short, writable folder,
then open the launcher inside it. Keep all bundled files together. The launcher
supports the Windows download marks on its verified WebView2 libraries.

The supplied archives and original source bytes remain recoverable under
`provenance/`. Short aliases preserve deep original reference paths. Current
integration and refresh evidence is under `validation/combined-release.json`;
older reports retain their original version, date and scope.

Numerical modules remain distinct. Local Maxwell/Drude matter and periodic MHD
are not a matched black-hole spacetime evolution. The aperture rule is a
postulate, the wormhole shape is a presentation mapping, and the EHT geometric
references failed their held-out test. No NASA qualification is claimed.
